# Решение проблем с GUI

## Если появляется ошибка "Ошибка генерации изображения":

### Причина 1: Кэширование модулей
Python запоминает импортированные модули. После обновления кода нужно:

**Решение:**
1. Закрой GUI (если открыт)
2. Перезапусти терминал/командную строку
3. Запусти заново: `python gui.py`

### Причина 2: Не установлен Pillow
Для отображения изображений нужна библиотека Pillow.

**Решение:**
```bash
pip install Pillow
```

### Причина 3: Нет прав на запись
Приложение сохраняет картинки в папку `generated_images/`.

**Решение:**
Убедись что есть права на запись в папку проекта.

## Быстрая проверка работы

```bash
# Проверить генерацию изображений
python test_gui.py

# Должно вывести: SUCCESS: C:\...\pixel_city_XXX.png
```

## Если всё равно не работает

1. Проверь версию Python: `python --version` (нужна 3.8+)
2. Переустанови зависимости: `pip install selenium Pillow python-dotenv`
3. Закрой все окна Python из Диспетчера задач
4. Запусти заново: `python gui.py`

## Важно!

- Генерация изображений теперь через Pollinations.ai — **быстро (10-20 сек)**
- Шедеврум через веб НЕ используется (требует авторизации)
- DeepSeek ключ опционален — без него только картинки работают
