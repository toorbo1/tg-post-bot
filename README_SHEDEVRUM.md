# Проблема с Шедеврумом

## Почему не работает кнопка "Шедеврум (качество)"

Шедеврум требует **авторизацию через Яндекс** для использования веб-версии. Без этого:
- Страница перенаправляет на `passport.yandex.ru`
- Нельзя ввести промпт
- Нельзя сгенерировать изображение

## Как заставить работать

### Вариант 1: Авторизоваться вручную
1. Открой Chrome
2. Перейди на https://shedevrum.ai/
3. Войди через Яндекс аккаунт
4. Оставь вкладку открытой
5. Запусти приложение и попробуй снова

### Вариант 2: Использовать Pollinations
Нажми кнопку **"Pollinations (быстро)"** — работает сразу, без авторизации!

## Что лучше

| Сервис | Время | Нужна авторизация | Качество |
|--------|-------|-------------------|----------|
| **Pollinations** | 10-20 сек | ❌ Нет | Хорошее |
| **Шедеврум** | 1-3 мин | ✅ Да (Яндекс) | Отличное |

**Рекомендация:** Используй Pollinations для быстрой генерации, Шедеврум только если нужно максимальное качество и есть Яндекс аккаунт.
