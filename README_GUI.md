# GUI для генератора постов

## Быстрый старт

### 1. Установи зависимости
```bash
pip install selenium Pillow python-dotenv
```

### 2. Получи API ключ DeepSeek (опционально)
- Иди на https://platform.deepseek.com/api_keys
- Создай аккаунт и сгенерируй ключ
- Добавь в `.env`: `DEEPSEEK_SESSION_ID=твой_ключ`

**Без ключа тексты не генерируются, но картинки работают!**

### 3. Запусти приложение
```bash
python gui.py
```

## Интерфейс

### Кнопки:
- **Сгенерировать пост** — запускает генерацию текста + картинки
- **Выход** — закрывает приложение

### Вкладки:
1. **Текст поста** — здесь появляется сгенерированный текст
2. **Изображение** — показывает картинку после генерации
3. **Настройки** — информация об API ключах

## Как работает

### Генерация изображения:
1. Открывает Шедеврум в браузере (Chrome)
2. Вводит промпт "pixel art cyberpunk city..."
3. Ждёт завершения генерации (30-120 секунд)
4. Скачивает и обрезает до формата 4:3
5. Показывает в приложении

### Генерация текста:
1. Отправляет запрос к DeepSeek API
2. Получает большой пост (10-12 абзацев)
3. Показывает во вкладке "Текст поста"

## Важно!

- **Шедеврум через веб** занимает 30-120 секунд — это нормально!
- Первый запуск может быть медленнее (загрузка Chrome)
- Без DeepSeek ключа работает только генерация картинок

## Troubleshooting

**Ошибка "Chrome not found":**
- Установи Google Chrome: https://www.google.com/chrome/

**Ошибка "Selenium error":**
- Переустанови: `pip install --upgrade selenium`

**Картинка не показывается:**
- Проверь интернет соединение
- Подожди 2-3 минуты (Шедеврум может тормозить)
