# Telegram Post Generator Bot

Бот для автоматического создания постов с ИИ-генерацией и публикацией в Telegram-каналы.

## Возможности:
- **ИИ-генерация контента** — уникальные посты через DuckDuckGo AI (без API ключа)
- **Разнообразие форматов** — короткие/длинные посты, с фото/без, разные стили
- Автоматический поиск релевантных фото из интернета без повторов
- Интерактивные кнопки: смена картинки, перегенерация текста, мгновенная публикация в настроенный ТГ-канал
- Автоматический запуск как systemd служба на Debian 13

## Новые команды:
- `/ai_post тема` — сгенерировать уникальный пост через ИИ по заданной теме
- Бот автоматически выбирает стиль: неформальный, экспертный, короткий, развернутый или история

## Развертывание на сервере Debian 13 (144.31.25.159):

1. Скопируйте папку `tg-post-bot` на ваш сервер в `/root/tg-post-bot`:
   ```bash
   scp -r C:\Users\User\Desktop\tg-post-bot root@144.31.25.159:/root/
   ```

2. Подключитесь к серверу по SSH и запустите скрипт установки:
   ```bash
   ssh root@144.31.25.159
   cd /root/tg-post-bot
   bash deploy.sh
   ```

3. Готово! Бот будет работать постоянно в фоновом режиме через `systemctl`
